# Data Cleaning & Preparation

## Project Overview

This project focuses on cleaning and preparing a raw dataset using Python and Pandas. The dataset was checked for missing values, duplicates, incorrect date formats, and numeric data types.

## Tasks Performed

- Identified missing values
- Handled 309 missing CouponCode values
- Checked duplicate OrderIDs and duplicate rows
- Verified date formats
- Verified numeric data types
- Created a cleaned Excel dataset

## Dataset Information

- Rows: 1200
- Columns: 14

## Tools Used

- Python
- Pandas
- Excel

## How to Run

1. Install Python.
2. Install required libraries:
   
   `pip install pandas openpyxl`

3. Run the Python script:
   
   `python data_cleaning.py`

## Output

The cleaned dataset is saved as:

`Cleaned_Data_Python.xlsx`
