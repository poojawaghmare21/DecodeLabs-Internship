# Data Analytics Project 3: SQL Data Analysis

## Project Objective

The objective of this project is to use SQL queries to extract insights from a dataset.

This project focuses on SQL fundamentals such as selecting data, filtering records, sorting data, grouping data, and performing basic aggregations.

## Dataset

The dataset contains 1,200 order records.

The `orders` table contains the following columns:

- OrderID
- Date
- CustomerID
- Product
- Quantity
- UnitPrice
- ShippingAddress
- PaymentMethod
- OrderStatus
- TradingNumber
- ItemsInCart
- CouponCode
- ReferralSource
- TotalPrice

# SQL Analysis

## 1. Create and Select the Database

```sql
CREATE DATABASE DataAnalytics_Project3;
USE DataAnalytics_Project3;

CREATE DATABASE is used to create a new database named DataAnalytics_Project3.
USE selects the database so that SQL queries can be executed on it.

2. Count Total Records
SELECT COUNT(*) AS Total_Records
FROM orders;

COUNT(*) counts the total number of records in the orders table.
The result showed that the dataset contains 1,200 records.

3. View Sample Records
SELECT * FROM orders
LIMIT 5;

SELECT * displays all columns from the orders table.
LIMIT 5 displays only the first five records.
This query was used to verify that the imported data was available in the table.

4. Display All Records
SELECT *
FROM orders;

This query displays all records and all columns from the orders table.
It was used to view the complete dataset.

5. Count Orders for Each Product
SELECT Product, COUNT(*) AS Total_Orders
FROM orders
GROUP BY Product;

GROUP BY Product groups the records according to product.
COUNT(*) counts the number of orders for each product.
This helps analyse the number of orders associated with each product.

6. Calculate Total Sales by Product
SELECT Product, SUM(TotalPrice) AS Total_Sales
FROM orders
GROUP BY Product;

SUM(TotalPrice) calculates the total sales amount.
GROUP BY Product calculates the total sales separately for each product.
This helps analyse total sales generated by each product.

7. Calculate Average Sales by Product
SELECT Product, AVG(TotalPrice) AS Average_Sales
FROM orders
GROUP BY Product;

AVG(TotalPrice) calculates the average value of TotalPrice.
GROUP BY Product calculates the average separately for each product.
This helps understand the average sales amount associated with each product.

8. Identify Different Order Statuses
SELECT DISTINCT OrderStatus
FROM orders;

DISTINCT is used to display only unique values.
This query displays the different order statuses available in the dataset.

9. Filter Shipped Orders
SELECT *
FROM orders
WHERE OrderStatus = 'Shipped';

WHERE is used to filter records based on a condition.
This query displays only the orders whose status is Shipped.

10. Display Highest Total Price Orders
SELECT *
FROM orders
ORDER BY TotalPrice DESC
LIMIT 10;

ORDER BY TotalPrice sorts the records according to TotalPrice.
DESC sorts the values from highest to lowest.
LIMIT 10 displays only the first 10 records.
This query helps identify the orders with the highest total price.

11. Display Lowest Total Price Orders
SELECT *
FROM orders
ORDER BY TotalPrice ASC
LIMIT 10;

ASC sorts the values from lowest to highest.
LIMIT 10 displays the first 10 records after sorting.
This query helps identify the orders with the lowest total price.

12. Calculate Total Sales by Payment Method
SELECT PaymentMethod, SUM(TotalPrice) AS Total_Sales
FROM orders
GROUP BY PaymentMethod;

GROUP BY PaymentMethod groups the orders according to their payment method.
SUM(TotalPrice) calculates the total sales for each payment method.
This helps analyse sales according to different payment methods.

13. Count Orders by Order Status
SELECT OrderStatus, COUNT(*) AS Total_Orders
FROM orders
GROUP BY OrderStatus;

GROUP BY OrderStatus groups the orders according to their status.
COUNT(*) counts how many orders belong to each status.
This helps understand the distribution of orders across different order statuses.


SQL Concepts Used

SELECT-
Used to retrieve data from the table.

WHERE-
Used to filter records according to a specific condition.

ORDER BY-
Used to sort data in ascending or descending order.

GROUP BY-
Used to group records based on a particular column.

COUNT()-
Used to count the number of records.

SUM()-
Used to calculate the total of numeric values.

AVG()-
Used to calculate the average of numeric values.

DISTINCT-
Used to display unique values.
